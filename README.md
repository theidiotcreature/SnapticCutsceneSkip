# <img src="https://github.com/theidiotcreature/SnapticCutsceneSkip/blob/main/data/gdpatch/mods/cutsceneskip/icon.png" alt="drawing" width="40"/> CutsceneSkip

mod for SNAPTIC Demo that uses a small patcher to force fail all cutscene calls

very hastily thrown together since cutscenes were annoying me so please report any issues to @theidiotcreature on discord

(valence being uninteractable is intended though may be subject to change)

### download:

get the latest release [here](https://github.com/theidiotcreature/SnapticCutsceneSkip/releases/latest)

this mod has integration with [SnapticBase](https://github.com/xNasuni/SnapticBase)
